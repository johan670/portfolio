# Johan Pihl — Design Principles

These are my standards. When I critique work — mine or anyone else's — this is what I'm measuring against.

---

## The short version

Clutter is failure. Craft is everything. Every element earns its place or it doesn't exist.

---

## Principles

### 1. Remove before you add
My first instinct when something feels wrong is almost always to take something away, not add something new. Visual noise is the most common design failure I see — too many weights, too many sizes, too many competing elements all asking for attention at once. If a page feels busy, something doesn't belong there.

Inspired by Dieter Rams: *"Good design is as little design as possible."*

### 2. Craft shows in the details no one notices consciously
The best-designed things feel effortless. That feeling is earned through decisions that are invisible to the user but would be noticeable if they were wrong — the right optical adjustment to a line of type, the spacing that creates just enough breathing room, the transition timing that doesn't draw attention to itself. Craft is not decoration. It's the absence of friction.

### 3. Typography is the design
On most screens, 80% of what the user sees is text. Getting type right — scale, weight, tracking, leading, measure — is not a finishing step, it's the foundation. If the typography is wrong, nothing else can save the design. The grid and the type should feel inevitable, not chosen.

Influenced by: Swiss International Style, Müller-Brockmann, Helvetica as a system.

### 4. The grid is a tool for thinking, not a prison
Everything should feel ordered, but not rigid. A clear grid creates visual trust — the reader's eye can predict where things are, which means cognitive load drops and they can focus on the content. But the grid exists to serve the work. Break it intentionally when it creates more meaning than following it would.

### 5. Hierarchy is a design decision, not an afterthought
Before I place anything on a page I ask: what does the reader need to see first, second, third? Every level of the hierarchy should be visibly distinct. If two things look the same, they are the same — so if they're not, make them different.

### 6. Color is a statement, use it like one
My default is near-monochrome. Color has impact because it's rare. One accent used consistently has more power than five shades used loosely. If I reach for color, I ask: is this doing work, or is it decoration?

### 7. Nothing accidental
Every margin, every weight, every line of copy should be there for a reason I can articulate. "It looked right" is a valid instinct, but I should be able to trace that feeling back to a principle. Design decisions I can't explain are design decisions I haven't finished making.

## What I'm checking in a critique

When I review a design — mine or someone else's — I'm asking:

1. **Clutter** — What doesn't need to be here? What could be removed without losing meaning?
2. **Hierarchy** — Can I read the page in the order it intends? Is each level distinct?
3. **Typography** — Does the type system feel systematic? Is anything an exception that shouldn't be?
4. **Spacing** — Is the whitespace intentional? Does the rhythm feel consistent?
5. **Color** — Is every color doing a job? Is anything decorative?
6. **Craft** — Are the details right? Transitions, alignment, optical adjustments, alt text?
7. **Consistency** — Does everything feel like it belongs to the same system?

---

## What I'm not interested in

- Trends for their own sake
- Complexity that signals effort rather than solving a problem  
- Decoration that doesn't carry meaning
- Safe, forgettable work
